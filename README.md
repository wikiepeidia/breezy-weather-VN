# Weather VN Experimental Fork

This repository is a personal hobby fork of Breezy Weather that I use for Vietnam-specific geocoding, LocationIQ integration, packaging changes, and other build experiments.

It is not an official Breezy Weather repository, not affiliated with the Breezy maintainers, and not a contribution target. I generally do not want unsolicited pull requests, feature requests, or upstream review traffic here.

If your work is meant for Breezy Weather itself, send it to the upstream project instead:

- Upstream project: <https://github.com/breezy-weather/breezy-weather>
- This fork: <https://github.com/wikiepeidia/vn-weather-with-locationiq-and-nominatim>

Releases in this fork, if any, are ad hoc personal builds with no support or stability guarantees.

For this fork specifically:

- Source code: <https://github.com/wikiepeidia/vn-weather-with-locationiq-and-nominatim>
- Privacy note: see [PRIVACY.md](PRIVACY.md)
- Install/use: clone and build locally, or use a release from this fork if I publish one

The upstream LGPL license [LICENSE.md](LICENSE) still applies. Branding and application/package identity are intentionally changed here so this fork is not confused with the official Breezy Weather app.
